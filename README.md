# CaixaGo Alpha 0.0.1

Primeira versão executável do CaixaGo.

## Recursos

- Splash Screen
- Login com usuário lembrado e PIN
- Home inicial
- Tema Dark
- Estrutura modular

## Como executar

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
